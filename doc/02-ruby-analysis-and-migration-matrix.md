# 02 — Ruby system analysis and migration matrix

Reference project (unchanged): `/home/rnardi/Documentos/NetDef/netdef-ci-github-app`
(Ruby ≥ 3.1.2, Sinatra/Puma, ActiveRecord via `otr-activerecord`, Delayed Job, Octokit, ~10.5k lines of code + ~4.3k of specs).

## What was analyzed

`AGENTS.md`, `README.md`, `doc/` (onboarding 01–05, `ci/ci.md`, setup/deploy PDFs), `app/`, `lib/`, `workers/`, `config/`,
`db/` (migrations and `schema.rb`), `deployment/`, `bin/`, `Rakefile`, `config.ru`, `Gemfile(.lock)`, `.github/workflows`, `spec/` and `reports/`.
The applicable AGENTS.md is the one from the Ruby project (Ruby style/structure rules); the Python directory had no AGENTS.md — one was created (`/AGENTS.md`).

### Identified flows, endpoints, events and integrations

| Topic                     | Analysis result                                                                                                                                                                                                                                         |
|---------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Endpoints                 | `POST /*` (GitHub webhooks, any path), `POST /update/status` (Bamboo), `POST /slack`, `POST /slack/settings`, `GET /metrics`, `GET /telemetry`, `GET /ping`                                                                                             |
| GitHub events             | `ping`, `pull_request` (`opened`/`synchronize`/`reopened`), `check_run` (`rerequested`), `check_suite` (`rerequested`), `issue_comment` (`ci:retry`, `ci:rerun [#sha]`), `installation`; anything else → 401                                            |
| GitHub App permissions    | Metadata (read), Checks, Issues, Pull requests and Discussions (read and write) — per `doc/release/setup/github_app_setup.pdf`; subscribed events: Check run, Check suite, Issue comment, Pull request, Discussion comment, Pull request review comment |
| GitHub App authentication | JWT RS256 (`iss` = App ID, validity ~10 min) → `GET /app/installations` (first installation) → installation token; **a new token per `Github::Check` instance**, no cache                                                                               |
| Webhook validation        | HMAC-SHA256 of the raw body with `auth_signature.password`; `Signature` or `X-Hub-Signature-256` header; the same secret is sent to Bamboo (`signature_secret`), which signs the callbacks                                                              |
| Persistence               | PostgreSQL, 13 domain tables + `delayed_jobs` (schema in `db/schema.rb`, version 2025_08_22_071834)                                                                                                                                                     |
| Queues/async              | Delayed Job: numeric queues 0–9 (`github_pr_id % 10`) and named ones (`create_execution_by_*`, `timeout_execution`, `fetch_topotest_failures`); 5 attempts, `max_run_time` 5 min, `sleep_delay` 5 s                                                     |
| Scheduled routines        | `TimeoutExecution` (self-rescheduling, 30 min), external cron: `watch_dog.rb`, `pr_bamboo_sync.rb`; manual: `single_sync.rb`, `bin/console`                                                                                                             |
| Integrations              | GitHub (Checks, Pulls, Issues/Reactions, Users), Bamboo REST (`https://127.0.0.1`, TLS without verification, credentials from `~/.netrc` `ci1.netdef.org`), Slack bot (`slack_bot.netdef.org` via netrc + `slack_bot_url`), Prometheus                  |
| Secrets/config            | `config.yml` (`auth_signature.password`, `github_apps[]` login/cert/repo, `metrics_auth`, `slack_bot_url`, `debug`, `multi_plan?`, `ci.url`), `database.yml`, `~/.netrc`, `.pem` keys                                                                   |
| Dev × production          | `RACK_ENV`; dev on port 9292 (`rackup`), production on 4667 via `deployment/server.sh` (migrates and starts) and `github_server.service` (user `githubchecks`, `/home/githubchecks/server`)                                                             |

Code × documentation divergences and questionable behaviors are in [`07-divergences-and-improvements.md`](07-divergences-and-improvements.md).
